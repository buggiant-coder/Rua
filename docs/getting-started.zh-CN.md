# Rua 使用入门

Rua 在每台设备上运行自己的 AI 助手。你可以在电脑或 Android 手机上聊天、使用本机工具，并将任务交给已配对的另一台设备。当前为预发布软件，请先使用测试数据。

## 安装前准备

准备一个模型服务账号、API Key 和模型名称。模型调用可能按服务商规则收费；安装 Rua 不包含模型额度。仅使用本机模型时，需要另外配置可访问的模型服务。

从项目维护者公布的正式发布页下载与你的系统和处理器匹配的安装包，并核对同一发布版本提供的 SHA256SUMS。当前源码中的发布配置不代表四个平台的安装包已经发布。

| 系统 | 计划提供的应用 | 当前源码状态 |
| --- | --- | --- |
| Windows x64 | 桌面安装程序 `.exe` | 已有打包流程，正式包依赖发布签名配置 |
| macOS Apple Silicon / Intel | `.dmg` 中的 Rua.app | 已有打包流程，正式包依赖签名与苹果公证 |
| Linux x64 | 独立桌面 `.deb` | 已加入打包入口，待原生 Linux 构建和安装验收 |
| Android ARM64 | `.apk` | 已有打包入口；当前使用公开测试密钥，正式发布身份待配置 |

Android 当前要求 Android 8.0（API 26）或更新版本；实际支持范围以该版本发布说明中的设备验收为准，不提供 x86 Android APK。

macOS 将应用拖入“应用程序”，Windows 运行安装程序。Android 在系统安装提示中仅允许本次下载来源安装 APK，完成后打开 Rua。未签名或测试签名构建可能被系统提示风险，不要因此关闭全局系统保护。

## 首次启动

桌面应用会启动本机 Rua 服务并打开独立窗口。Android 首次启动会自动下载并校验 Debian、Python、Node 等工具环境，需要网络和一定等待时间；可查看准备进度、取消、重试或导入离线材料。常规启动不应重复安装可用环境。

进入设置中的模型配置，选择服务商，填写 API Key，选择可用模型；兼容服务还需要填写服务地址。保存后创建聊天并发送一条简单问题，确认回复正常。不要把 API Key 发到聊天、截图、日志或公开 issue 中。

先让助手读取一个专门建立的测试目录。需要执行命令或修改文件时，检查它请求的权限和确认提示。Android 的存储、通知、无障碍等权限按需要授予；桌面自动化可能需要操作系统授权。PRoot 提供 Linux 兼容环境，不是安全沙箱。

## 多设备使用

在各设备安装同一发布版本，进入设置中的设备同步页面，按照页面提示配对自己的设备。确认设备列表中的名称和配对对象，再开始同步。聊天时检查执行目标：本机执行使用本机文件和工具，远端执行使用所选设备的文件和工具。对方设备需要在线，相关工具也必须可用。

## 工具与技能

MCP、技能、插件和外部编码助手需要分别配置其运行环境与账号。安装 Rua 不表示第三方工具已全部安装或获得授权。先从可信来源添加一个工具并做小范围验证。技能使用方法见 [技能指南](skills-user-guide.md)，语音和消息渠道的配置见 [渠道指南](channels.md)。

## 更新与卸载

正式桌面更新需要验证维护者签名；手动安装时选择同一发布渠道。Android 覆盖安装必须使用兼容的签名身份，测试版和正式版可能无法直接互相覆盖。更新和卸载前备份重要数据，不要为解决安装冲突直接删除应用数据。

桌面用户数据默认在 `~/.rua`，也可能由用户选择其他目录；删除桌面应用通常保留数据。Android 卸载会删除应用私有数据。对外提交问题时只附脱敏日志，并注明系统、版本、处理器和复现步骤。

## 从源码运行

需要 Rust 1.91+、Node.js/npm、Python 3、protoc 和 sccache，以及操作系统对应的编译工具。完整桌面系统依赖见 [Tauri 前置要求](https://v2.tauri.app/start/prerequisites/)。仓库默认使用 sccache；不安装时可为单次构建设置 `RUSTC_WRAPPER=`。

```bash
cd console
npm ci
cd ..
RUA_ROOT="$HOME/.rua-dev" cargo run -p rua-cli -- init
RUA_ROOT="$HOME/.rua-dev" cargo run -p rua-cli -- server start --host 127.0.0.1 --port 8765 --no-auth
```

另开一个终端启动前端：

```bash
cd console
npm run dev
```

开发界面为 `http://127.0.0.1:5173`，开发 API 为 `http://127.0.0.1:8765`。这个开发入口关闭认证，仅用于本机开发，不要将它直接暴露到公网。模型也可通过 `cargo run -p rua-cli -- setup-env` 配置。

Android 编译见 [Android 构建说明](android-packaging.md)。桌面打包入口为
[build-desktop.sh](../scripts/ci/build-desktop.sh)，签名要求见[发布签名说明](release-signing.md)。
